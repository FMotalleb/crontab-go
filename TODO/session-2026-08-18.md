## Debugging note

The timeout test initially took 5s despite the process being killed at 200ms. Bisected to `cmd.Stdout/Stderr` being non-`*os.File` writers: the orphaned `sleep` grandchild keeps the pipe write-end open, so `Wait` blocks until it exits. Fixed via `WaitDelay`. Root cause of the 5s confirmed empirically; the debug scratch test was deleted after use.
